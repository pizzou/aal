Provider UAT requires real sandbox/production credentials and a provider-approved test object.

Brevo:
  BREVO_API_KEY=...
  AAL_MAIL_FROM=...
  UAT_EMAIL=...
  ./scripts/provider-uat/brevo-smoke.sh

Aviationstack:
  AVIATIONSTACK_API_KEY=...
  AVIATIONSTACK_TEST_FLIGHT=...
  ./scripts/provider-uat/aviationstack-smoke.sh

Generic HTTP provider:
  PROVIDER_NAME=...
  PROVIDER_URL=...
  PROVIDER_API_KEY=...
  ./scripts/provider-uat/http-check.sh
